# 0004 单文件 SQLite、better-sqlite3 与显式迁移闸门

## Status

accepted（2026-11-03）

## Context

GLOSSARY.md 已经规定业务状态的唯一正本是后端单文件库，库文件落在数据目录（`~/.allibot/data/allibot.db`），迁移必须显式执行、迁移前自动整目录备份、单事务收口、`schema_meta.schema_version` 与代码常量比对。用户已定夺 D1：业务正本使用单文件 SQLite（better-sqlite3 或 drizzle + better-sqlite3，二者择一并写明理由），库文件落在数据目录；迁移保留显式 `--migrate`、备份、单事务与版本闸门。新仓是零源码，必须选择数据访问层，并从第一版起把迁移纪律写死。

## Decision

1. **选 better-sqlite3，不选 drizzle**。理由：
   - 本仓是单用户、单进程、本地优先的工作台；better-sqlite3 的同步 API 与「唤醒编排在进程内顺序执行」的形状一致，`db.transaction()` 可以直接把消息落库、seq 分配、提及快照、附件绑定与唤醒信号收进一个事务。
   - 词条要求数据库级触发器（消息 append-only、附件不可改、指针消息的 BEFORE INSERT 校验）与部分唯一索引；这些必须用原生 DDL 表达。drizzle 的 schema 层会与手写 DDL 形成第二套 schema 来源，迁移工具也会与显式 `--migrate` 步骤链冲突。
   - 仓库规模小、查询形状固定（target 内 seq、未读计数、预算行、任务看板）；手写 SQL + 轻量行映射比 ORM 更短、更可审计。YAGNI：当前没有需要 ORM 的复杂关系或跨库查询。
   - 代价是类型安全靠手写映射与测试兜底；这个代价由「一条主 seam + 脚本化 provider」的测试策略吸收。
2. **单文件库**：`allibot.db` 位于数据目录；数据目录还承载 `attachments/` 与 `schema-migrations.jsonl`。不启用需要额外旁文件的模式作为默认；如果实现票选择 WAL，备份单位仍是整目录，不改变「数据目录是备份单位」的口径。
3. **写事务纪律**：消息 append-only；`seq` 由单写者事务内 `MAX(seq)+1` 分配并由 `UNIQUE(target_id, seq)` 兜底；消息、提及快照、附件绑定、`round_outcome`、预算推进与唤醒信号在同一边界内收口。跨表的「认领」「任务创建 + 指针消息」「预算跳扣减」各自一个事务。
4. **迁移**：显式 `--migrate`，启动路径不迁移。迁移前自动对整个数据目录建一份同级备份；备份失败就不迁移。数据库变更在一个事务内收口；审计台账是数据目录内的 append-only JSONL，记录 from / to / 起止时间 / 结果 / 备份路径，失败也记。代码里的 `SCHEMA_VERSION` 常量与 `schema_meta.schema_version` 比对；不等时启动路径拒绝启动、迁移入口拒绝执行；库版本高于代码版本一律拒绝，不提供降级路径。回滚 = 恢复迁移前整目录备份，再用旧代码打开；改回 `SCHEMA_VERSION` 不算回滚。
5. **版本号空间**：本仓是全新 schema，基线为 `1`，按严格 +1 的步骤链推进。GLOSSARY 记录的旧仓 15 → 25 十个步骤属于上一代仓库历史，不复制、不补号；本仓第一条迁移就是 `1` 的初始形态。号只表示形态，不表示迁移次数。
6. **数据目录解析**：默认 `~/.allibot/data/`，`--data-dir` 或 `allibot_DATA_DIR` 覆盖；解析顺序为「显式覆盖 → 新默认存在 → 旧 `~/allibot` 存在（兼容读取并提示）→ 新建新默认」，绝不自动搬移旧数据。备份数据目录不等于备份项目文件或全局层；本仓 M1 没有项目根文件工具，也没有全局层，备份边界按词条口径说明。

## Consequences

- 数据层简单、可审计、启动快；所有写路径都必须经过显式事务，绕过事务的写入会被代码评审拒绝。
- 没有 ORM 的类型生成；行类型、查询与迁移测试需要手写。迁移步骤链的测试比 ORM 自动迁移更重，但换来「启动不会偷偷改库」这条产品纪律。
- 单进程假设写死：一个数据目录同时只允许一个后端进程写入；多进程或云同步不在本仓范围。若未来要支持多实例，需要重新审视本 ADR，而不是在 SQLite 上叠锁。
- 旧仓的 `SCHEMA_VERSION=25` 与本仓 `1` 并存会让读过 GLOSSARY 的人困惑；规格与迁移命令的输出必须明确「这是新仓基线，不是回退」。
